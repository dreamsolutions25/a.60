# Agnes: A Legacy of Grace

PROJECT BRIEF: MRS AGNES ADU GYAMFI ADJEI – 60 YEARS OF EXCELLENCE

Premium Interactive E-Invitation Web Application

PROJECT OVERVIEW

Design and develop a premium, elegant and fully functional digital e-invitation website celebrating the 60th birthday and retirement of Mrs Agnes Adu Gyamfi Adjei.

The website should serve as a beautiful digital invitation that guests can open through a shared link, explore the celebrant's professional journey, view photographs, access event information and leave personal messages for the retiree.

This should not look like a typical birthday website or a generic event landing page. It should feel like a luxury editorial publication combined with an exclusive celebration invitation.

The overall experience should communicate:

Grace

Excellence

Legacy

Dedication

Achievement

Gratitude

Celebration

The website must be visually impressive, mobile-first, responsive and fully functional.

1. VISUAL IDENTITY & DESIGN SYSTEM

Design Concept: CHAMPAGNE ELEGANCE

Use a refined luxury aesthetic inspired by high-end editorial magazines, elegant wedding invitations and premium celebration stationery.

The visual direction should be predominantly ivory and champagne gold, supported by subtle beige and warm neutral tones.

Colour Palette

Warm Ivory: #F8F5EF – Primary background.

Champagne Gold: #C6A46A – Primary accent.

Soft Beige: #EAE1D3 – Secondary background.

Deep Charcoal: #292722 – Primary text.

Muted Taupe: #8C8172 – Secondary text.

White: #FFFFFF – Card surfaces.

Gold should be used sparingly for fine borders, dividers, decorative details and important typography. Do not make the entire website gold.

Typography

Use elegant serif typography for major headings:

Cormorant Garamond

Playfair Display

Use a clean sans-serif for body text:

Inter

Manrope

Large headings should have a sophisticated editorial appearance, with generous spacing and carefully considered line heights.

Visual Characteristics

Generous whitespace.

Minimalist layouts.

Elegant thin-line borders.

Subtle champagne-gold accents.

Large editorial photography.

Beautiful image compositions.

Refined section transitions.

Soft fade-in animations.

Delicate decorative elements.

Smooth scrolling.

Avoid:

Excessive gradients.

Bright colours.

Cartoon illustrations.

Generic AI-generated website layouts.

Excessive rounded cards.

Unnecessary icons.

Overly decorative floral graphics.

Cluttered layouts.

The result should feel timeless, elegant and professionally art-directed.

Security Requirements

Enable Row Level Security on all relevant database tables.

Public visitors can submit messages.

Public visitors cannot read private or pending messages.

Only authorised administrators can manage messages and photographs.

Protect all administrative operations.

Validate uploads and restrict acceptable file types and sizes.

Never expose Supabase service-role keys in frontend code.

Use secure authentication and proper database policies.
